# Upscale AI

Upscale AI (upscale.com, formerly upscaleai.com) is a pure-play AI networking infrastructure company based in Santa Clara, CA — a full-stack, open-standards AI fabric (SkyHammer scale-up ASIC architecture plus NVIDIA Spectrum-X/SONiC-based scale-out Ethernet systems) for large-scale AI training and inference. Founded by veterans of Palo Alto Networks, Marvell, Cisco, and Google (CEO Barun Kar); $500M raised at a $2B valuation, backed by Mayfield among others.

Surfaced as a portfolio company of Mayfield. The company publishes no public API, developer portal, or SDKs — this profile captures its corporate surface (site, llms.txt, domain security posture) for the API Evangelist network.
